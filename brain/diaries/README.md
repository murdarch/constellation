# Diaries

One file per seat, `<seat-name>.md`, newest entry first. The diary is
the one artifact nobody else may write for a seat — its own voice, its
own judgment of the day. Entry format lives in the handoff skill
(`.claude/skills/handoff/SKILL.md`).

Diaries are identity; the ledger is work state. Where they disagree,
the ledger wins — and the disagreement is worth a diary line.
